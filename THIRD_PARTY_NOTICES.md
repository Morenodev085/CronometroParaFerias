# 8StarLabs UI

`src/components/8starlabs-ui/flip-clock.tsx` adapts the Flip Clock component from
https://github.com/8starlabs/ui/blob/main/registry/8starlabs-ui/blocks/flip-clock.tsx
with Tailwind utilities, local color and size styles, and local variant maps
instead of class-variance-authority. Next.js-only style attributes were removed;
the animation keyframes live in `src/index.css`.
